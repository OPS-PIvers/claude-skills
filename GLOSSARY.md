# OPS brand

The vocabulary of the Orono Technology (OPS Tech) brand as the `ops-brand-guidelines` skill and its `DESIGN.md` use it.

## Language

**OPS voice**:
How Orono Technology materials read, whoever builds them. It is the district's voice, not any one person's.
_Avoid_: Paul's voice, brand tone

**Card**:
A bordered, self-contained container for a discrete object a person picks, opens, drags, or compares side by side. Never a way to group text, never nested.
_Avoid_: Panel, tile, box

**Callout**:
A tinted block with no border that sets apart one note the reader must not miss. It opens with a bold lead word that says what kind of note it is.
_Avoid_: Alert box, banner, aside

**Claim title**:
A content-slide title written as a sentence-case statement of the slide's point, such as "Exit tickets take 3 minutes".
_Avoid_: Assertion headline, action title

**Hairline divider**:
A 1px rule between items in a list, table, or set of sections. The default way to separate things that aren't cards.
_Avoid_: Separator, border line

**Stylesheet**:
The printed OPS Tech brand reference (`Resources/OPS Tech Stylesheet.pdf`). Its colors and type are canonical; it is being replaced so its components match the cleaned-up rules.
_Avoid_: Brand guidelines infographic, style guide
